# Hand-written travelers

Interim shop sheets for the oblique-trammel jig parts. They were written by hand and are not generated or checked by prechips. Print one from a browser at 100% scale. Each sheet names its drawing revision and sources at the bottom. The base bar has its 2026-10-27, 2026-10-30 and 2026-11-05 versions; the 2026-11-05 sheet follows the current drawing (Amazon kit rail, #2177) and the setup advice in the 2026-10-30 logbook entry. The feed lever (TL-26) and end bracket (TL-28) follow the decimal-inch drawings from PR #2112.

Prechips travelers generated from `cad/process/<stem>/plan.toml` will replace these. Delete each sheet when its replacement exists.

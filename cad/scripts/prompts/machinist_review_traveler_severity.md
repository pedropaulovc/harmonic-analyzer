Pass 2 — classification. Assign each distinct candidate exactly ONE defect
type: apply the specific cases named in the table first, and use this
precedence only when one defect meets more than one type:

    contradiction > missing > unbuildable > over_specification > wasted_work
        > presentation > head_layout > shortfall > polish

Then file it in that type's category. Never file one defect twice, never
invent a hybrid category such as "minor clarity", and never move a finding to
a lower category because it feels minor, because an experienced machinist could
work out the intent, or because the fix is easy — the type decides.

| type | what qualifies | category |
|---|---|---|
| contradiction | Traveler against companion part drawing: part number, revision, material, unit, feature count, size, tolerance band, datum reference or `SHARP` / edge-break requirement that disagrees (rules T1, T2, T14, 25). Traveler against itself: op text vs. `Tool / settings` column vs. `Holding` / `Datum` vs. setup diagram; broken `face 1` / `face 2` or reference-edge tracking across flips/reseats (rule T7); a `G54 unchanged` claim falsified by an intervening move or layer without stated program/operator offset (rule T6); conflicting tool `T` numbers, program names or clamp/plug states (rules T5, T8) | blockers |
| missing | A manufactured feature on the drawing with no producing op (rule T2), or a critical fit/registration feature with neither a printed check nor an explicit `process-held` / first-article check (rules T2, T10 — never demand 100% inspection of every `.X`/`.XX` feature); a shop-made fixture, sub-plate, plug, soft jaw or template that setups depend on with neither a drawing/make reference nor printed interface dimensions (rule T3); an adhesive or tape hold whose product/grade is unnamed when strength or breakthrough depends on it (rule T3); a fixed-Z cut that depends on variable stock size with no incoming measurement gate and stop (rule T4); an axis zero placed on no physical feature (rule T6); a flip/reseat that leaves face or datum-edge orientation ambiguous so a part can be mirrored or mis-datum'd (rule T7); a CNC traveler with no first-article program/clearance prove-out step (rule T8); a kept check with no acceptance criterion, an instrument unavailable in a well-equipped home shop such as a CMM or optical comparator (rules T0, T11), or a check whose named instrument cannot physically measure the toleranced quantity as written because slant/offset geometry shifts the reading outside/across the band with no workable route printed — arithmetic shown (rule T10); unresolved template placeholders (`{{…}}`, `?`, `NaN`) | blockers |
| unbuildable | Qualitative or printed-text sequence/handling traps the build gates do not check, with arithmetic shown where numeric (rule T9): hogging one side of thin cold-finished bar to final size without stress release where flatness/thickness bands govern; live side clamps left engaged across a through-cut pinching freed waste into a cutter; prying a thin bonded part from one end; leaving a plug/stop inside a relief bore while drilling into it, or a printed cut/drill depth contradicting the printed thickness + `0.3D` point; a hands-in step at a printed stop the sheet does not say is retracted with the spindle off; an in-process cut-to-number band narrower than "What the shop holds" with no fit/offset route (rule 4) | blockers |
| over_specification | **Over-inspection (rules T10, T15):** requiring per-piece lot gauging on CNC-repeated contours, angles, `.X`/`.XX` features or hole pitches that first-article prove-out already locks in; repeating a measurement with no intervening cut or stress release; surface-plate / sine-bar / gauge-block metrology rituals on loose title-block bands where calipers, a rule, a mate or the CNC program suffices; turning un-toleranced or `(REF)` features into pass/fail final acceptance (a rule T4 incoming-stock gate and a labelled in-process target are not over-inspection); final acceptance limits tighter than the part drawing's (rule T15); a plug gauge, a GO / NO-GO pin pair, a Class X pin or a single-size reamer named for a fit the part drawing accepts by its mate, or for a band the drawing does not print (rule T0); gauging every piece of a lot for a fit the mate itself proves at assembly; fixtures wildly disproportionate to a loose band; multi-sentence rationale essays inside op cells; restating the `Tool / settings` column verbatim without adding handoff detail; production QA paperwork — FAI/AS9102, sign-offs, lot/heat tracking, material certs, SPC, calibration logs or PPE boilerplate (rule T15) | over_specification |
| presentation | An op cell exceeding six printed lines on the sheet image or bundling unrelated setup stages without splitting into numbered ops (rule T12; list every offending op number); a check and its remedy merged or an in-process rework with no concrete action (`goes back for a skim` on a fixed-Z program without saying how, rule T10); a straightening or surface-plate flatness step with no concrete acceptance or recheck (rules T10, T17); missing `Z0` / tool-setter reference explanation or reset condition where a novice would have to guess (rule T6); clearance-governing hardware or clamps named only generically (`washer and screw`, a clamp named by brand without size/model, rule T3); a setup/inspection diagram leader landing in blank air or at an off-centre curved-edge station where the printed centreline band does not hold (rule T13); a legend word or fill used inconsistently or colliding with the part's own name (one word meaning both the part and a clamp while hardware uses that fill, rules T12, T13, 26); a CNC sub-op written like a separate manual start when it runs continuously inside one file (rule T12); hands-in action not tied to a named pause where non-hazardous, or clipped/overlapping rendered text (rule T13) | clarity |
| wasted_work | Rule T19, with both op numbers: a bench or finishing op (deburr, edge break, stone, polish, wash, mark, finish coat) on a surface or edge that a later op cuts, faces or re-machines; the same hand operation on the same feature in two setups with no printed reason for the first; a wash or finish-prep step followed by more machining. Never an early op a later cut, seat or check depends on (burrs off before a face seats, exits scraped flush and a no-rock check before a bolted pair is bored, a mark later setups orient by, a skim that gives the next datum), nor one whose reason the sheet prints. A route that only could be combined or reordered, nothing undone or repeated, is `polish` | over_specification |
| head_layout | Rule T18, on the rendered head of sheet 1 (stock line to Tools table): a paragraph, list item or table cell over 60 printed words, or a head printed as one paragraph of unrelated instructions; a collision, homing, re-zero or Feed Hold / Reset rule printed mid-paragraph rather than as its own labelled item, or a rule particular to this job not in a block of its own; a standing shop rule restated in different words in a second place (a different value or condition is a `contradiction`); a head sentence that only repeats what a setup page prints | clarity |
| shortfall | A departure covered by a supplied traveler `machinist_exceptions` entry (`kind: minor`), quoted with its value and exception id | minor |
| polish | Minor number/unit formatting (`0.010` vs `.010`, `0.5 ft-lb` vs `6 in-lb`, `1-1/2` vs `1 1/2`), minor machine-subtitle wording variation across setups, a direction-only `+X/+Y` triad placed beside rather than on `X0/Y0` when `Datum:` defines the zeros, omitting `T` numbers in the top Tools table when each op names both `Tn` and the tool, oiling a drill at low RPM, or style preferences that break no explicit rule | minor |

TRAVELER ADJUDICATION RULES (FOR BOTH REVIEWER AND JUDGE)
1. **Companion part drawing is reference-only:** Confirm cross-document claims
   by inspecting both the traveler sheets and any attached part-drawing sheets,
   but classify any critique of the part drawing's own tolerances, notes, views
   or layout as `misread` (judged by the drawing's own review).
2. **Build gates own cutting, holding & posted-program math:** Reject as
   `misread` any claim that recomputes spindle speed, chip load, deflection,
   vise or chuck holding, machine travel, pecking, declared gauge resolution
   against a band, or posted depths and retract heights (`prechips` and
   `cam:<stem>` check these; traveler guidelines "Division of labour"), or any
   complaint that ordinary home-shop hand tools are omitted from the Tools
   table. A contradiction the sheets themselves print (two statements that
   cannot both be obeyed, or a hands-in step at a stop the sheet does not say
   is retracted with the spindle off) is never covered by this rule. Adhesive
   and tape bond strength is not gated: judge it under rule T3.
3. **Arithmetic for physical & measurement claims:** Confirm a collision,
   clearance, breakthrough, drill-point or caliper-slant/measurability blocker
   only after working the arithmetic yourself from printed numbers and showing
   it in `reason`. If any ordinary configuration works, mark `misread`.
4. **PDF text-layer artefacts are `misread`:** Headless browser PDF text layers
   frequently split or double letters (`ToTools`, `off ff`, `Z .1 165`,
   scrambled SVG labels). Judge rendered pixels via `view_sheet` and `crop`;
   any claim grounded only in text-layer corruption is `misread`.

# KCL Archive

This folder contains KCL (KittyCAD Language) files that were created as experiments to understand the capabilities of Zoo and KCL for code-first CAD modeling.

**These files are no longer maintained** and are not kept in parity with the latest CAD models of the Harmonic Analyzer project. The project has since moved to SolidWorks for CAD development.

## Contents

- `*.kcl` - Experimental KCL model files
- `developing-kcl-skill/` - Claude Code skill configuration for KCL development (archived)

Now an ANSI-#25-proportioned roller chain: two link parts `chain-inner-link` (2 obround plates z ±0.6 + 2 bushings, vol 60.16) and `chain-outer-link` (2 plates z ±1.7 + 2 pins, vol 79.32) built by shared `_chain_link.build_link` (obround plate = bottom line + 2 end-arcs + top line, ALL geometry under direct_db True THEN constraints; Axis1/Axis2 via two_planes Top×Right / Top×offset-plane — `create_axis` cylindrical_face InsertAxis2 fails); 64 links (EVEN so inner/outer alternation closes the seam), `PITCH_NOMINAL`=6.35 mm seeds `LINK_COUNT=2·round(loop/2/6.35)`, exact-closure `LINK_PITCH`=6.2876. **KEY DECISION — EXPLICIT PLACEMENT, not the SolidWorks chain-component-pattern feature.** API research (skill docs `IChainPatternFeatureData` + the canonical Distance example + GoEngineer/Javelin tutorials): the create recipe is select-with-marks → `CreateDefinition(112)` → `CreateFeature(data)` immediately (AccessSelections is modify-only); but the **Distance** method chord-steps and rolls links out of plane on the tight wraps, and the authentic two-group **Connected-Linkage** variant has NO published API and raw-COM `CreateFeature` returns `None` (interactive-drag feature). **How to apply (standing user requirements):**
- Dimension annotations printed in the book's photos are the AUTHORITATIVE measurement source; dims in existing SLDPRT/C#/KCL files are derivative and possibly wrong — book wins on conflict.
- Every part AND assembly must ship with a Python reproduction script (`cad/scripts/build_<name>.py`, pattern `SolidworksMCP-python/scripts/demo_*.py`: async PyWin32Adapter, `_check()` per call, SLDPRT/SLDASM + PNG out, exit 0). The full pipeline rebuilds via `uv run python -m doit` (`build_all.py` was removed 2026-06-18).
- Every sketch must be fully defined (`check_sketch_fully_defined` passes).
- Every assembly's saved state must be fully defined too (user flagged under-defined mates 2026-06-10): no floating components, no free DOF — fix jig components, ground mechanism spin with angle mates (avoid redundant mates), and assert every top-level component is fixed or `swFullyConstrained` via `IComponent2::GetConstrainedStatus` (== 3; flag the dispatch with `_flag_feature_methods(component, "IComponent2")` first or the call raises). Acceptance fixtures must also look physically sensible — no interpenetrating pattern instances, nothing floating in space (mount on a plate/frame).
- Gears: fully parametric (equation-driven involute + ToothCount global + 20 configurations) — waits for MCP Phase 4; fallback per-tooth-count files only if configs prove unreliable.
- Measurement source of truth: `cad/config/dimensions.yaml` (method column: annotated/stated/scaled/legacy/derived; the generated `DIMENSIONS.md` was retired 2026-06-20).

# First-party photo index — `photogrammetry/raw/` (89 photos, 2025-08-28)

Photos of the actual machine in its display case (Altgeld Hall), shot through
glass with B/W photogrammetric scale bars taped to the case. Companion to
`cad/DIMENSIONS.md`: consult this index during each part build for details the
book photos don't show.

## Scale caveats (read first)

- **All scale bars are on the case glass/frame, NOT at component depth.**
  Parallax makes them unusable for direct part measurement; use them only for
  case-envelope and rough proportioning.
- **Best in-machine ruler: the nameplate, known 100 × 55 mm** (DIMENSIONS.md
  ch. 26). It is legible and roughly coplanar with the base-region components in
  `195445871`, `195448195`, `195527397`, `195530756` — use these to scale the
  cylinder/cone gear stack (closes the gear-module open item).
- Near-coplanar scale-bar exceptions: `195203981` + `195200658` (table-edge bar
  at base-casting depth — best for base scaling), `194959036` + `195001758`
  (case-top bars near counter-spring depth).
- Book annotations remain the authoritative dimension source; these photos are
  for detail inspection and secondary scaling.

## Details the photos add over the book

- **Tube frame columns are fluted/reeded, not plain round** (195108425,
  195123524) — groove count estimable; affects tube-frame part modeling.
- Top casting is a two-layer plate with a gray ribbed carrying handle and domed
  acorn cap nuts on the column studs (194105655, 195108425, 195459497).
- Tie-bar brackets clamp column pairs with slotted fillister-head screws
  (195129822); square-head bolts on the gear-housing window frame (195530756).
- Underside hardware of the summing-lever platform (194651412) — never shown in
  the book.
- Pen carriage: brass block + pivot + marker clamp with thumb screws
  (195442919); modern replacement, holds a Sharpie.
- Chain drive routing crank/cylinder-shaft → sprockets → platen gear fully
  traceable (194722591, 195405015 — upper sprocket teeth countable).
- Channel lever tips carry rectangular end blocks (195527397); lever ends are
  stepped/staggered in length (195524565).
- Rocker-arm pivot rod uses segmented spacer hubs (195503971, 195506228).
- Museum placard legible (195102348, 194620556): attributes machine to Gaertner
  & Co.; says "80 springs driven by 80 gear-wheels … 1/80, 2/80 … 80/80 turns"
  alongside "20 amplitudes" — the 1/80-per-crank gear law matches ch. 29, but
  the 80-element counts contradict the physical 20-channel machine; treat the
  placard as unreliable on counts, book wins.
- Display orientation confirmed vertical (tall axis up), matching the eight
  views in ch. 30.
